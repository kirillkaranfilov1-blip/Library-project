# 📚 Bookly

**Bookly** — современный библиотечный каталог, созданный на HTML, CSS и JavaScript.

Проект позволяет находить книги через Open Library API, просматривать подробную информацию, добавлять книги в личную библиотеку, отслеживать статус чтения и оставлять отзывы.

## ✨ Возможности

* 📖 Каталог книг
* 🔎 Поиск по названию, автору и жанру
* 📄 Пагинация книг

* 🔥 Сортировка по популярности
* 🔤 Сортировка по названию

* ✅ Статусы книг:

  * Прочитано

* 🗑️ Удаление книг из личной библиотеки
* 🔍 Фильтрация книг по статусу
* ✍️ Добавление отзывов
* ⭐ Оценка книг от 1 до 5 звёзд

## 📖 Основные страницы

### Главная

На главной странице находится каталог книг и поиск.

Пользователь может:

* найти книгу;
* открыть подробную информацию;
* посмотреть рейтинг;
* добавить книгу в личную библиотеку;
* перейти между страницами каталога.

### Мои книги

Страница личной библиотеки пользователя.

Здесь отображаются добавленные книги и статистика:

* всего книг;
* прочитано;
* в процессе;
* не прочитано.

Для каждой книги можно изменить статус или удалить её.

### Отзывы

Страница отзывов пользователей.

Оставить отзыв можно только о книге, которая имеет статус **«Прочитано»**.

При создании отзыва пользователь выбирает:

* книгу;
* оценку от 1 до 5 звёзд;
* текст отзыва.

Отзывы сохраняются в браузере.

## 💾 LocalStorage

Bookly использует `LocalStorage` для хранения данных пользователя.

Книги сохраняются под ключом:

text
myBooks


Отзывы сохраняются под ключом:

text
reviews


Поэтому данные сохраняются после перезагрузки страницы и доступны на других страницах проекта в том же браузере.

## 🌐 Open Library API

Для получения информации о книгах используется **Open Library API**.

API предоставляет данные о:

* названии книги;
* авторах;
* годе публикации;
* обложке;
* жанрах;
* рейтинге;
* количестве оценок.

## 🚀 Запуск проекта

1. Скачай или клонируй проект.
2. Открой папку проекта в Visual Studio Code.
3. Установи расширение **Live Server**.
4. Открой `index.html`.
5. Нажми **Go Live**.

После этого проект откроется в браузере.

## 🎯 Цель проекта

Цель проекта — создать удобную цифровую библиотеку, в которой пользователь может находить книги, сохранять их в свою коллекцию, отслеживать прогресс чтения и делиться своими впечатлениями.
